# Dashboard de acompanhamento processual

**Categoria:** Legal Operations  
**Status:** Em desenvolvimento

## Visão geral

Dashboard em desenvolvimento para automatizar o acompanhamento de atualizações processuais realizadas por escritórios de advocacia.

## Problema

Advogados precisam consultar processos manualmente para descobrir movimentações. É uma rotina repetitiva, que exige acessos recorrentes aos ambientes de consulta.

## Solução e fluxo proposto

O produto foi concebido para acompanhar processos cadastrados, identificar novas atualizações e avisar o advogado. Em seguida, a pessoa pode acessar o dashboard para visualizar a movimentação identificada.

1. O processo é cadastrado ou associado ao sistema;
2. O sistema acompanha as movimentações;
3. Uma atualização é identificada;
4. O advogado recebe uma notificação;
5. O advogado acessa o dashboard;
6. A nova movimentação é apresentada.
